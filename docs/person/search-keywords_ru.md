# Дополнительные слова для поиска персоны

Поле «Ключевые слова для поиска» доступно в общей форме создания и редактирования персоны на сайте и в CMS. Укажите слова через запятую, например `Кирилл, Немтырев`. Они не отображаются как теги профиля и не меняют адрес страницы.

Сервер хранит до 20 слов или фраз длиной до 80 символов в отдельной таблице `person_search_keywords` (Flyway V14). Пробелы нормализуются, регистр приводится к нижнему, дубликаты удаляются. Обычный поиск с прежним debounce и пагинацией ищет по имени, URL-тегу и дополнительным словам; совпадения по нескольким словам не дублируют персону. Символы `%` и `_` ищутся буквально.

Администратор сохраняет изменения сразу. Владелец использует существующий процесс согласования профиля: до одобрения поиск учитывает только опубликованные значения. Чужой аккаунт не может менять слова. Пустой список очищает их, отсутствующее или null-поле `searchKeywords` сохраняет текущие значения при обновлении старым клиентом. Изменение слов повышает версию профиля и защищено от сохранения устаревшей формы.
