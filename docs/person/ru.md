# Главная страница person

`frontend/person` — отдельное приложение Next.js/Gravity UI. Локальный адрес: `http://localhost:3002/ru` или `/en`. Шрифт Golos Text, темы, i18n, изображения и ID-клиент общие с остальными приложениями. Поиск обращается к backend/person после паузы 350 мс и открывает страницы персон по чистым адресам /{tag}. Подробности: [персоны, модерация и демо](domain_ru.md).

Главная занимает `100dvh` без прокрутки документа. Прозрачный хедер расположен поверх иллюстрации: отдельной цветной полосы над полотном нет. На узких экранах иллюстрации размещаются в нижней части полотна, чтобы не обрезать лица. Крупный заголовок печатается в двух явно заданных строках без дополнительных переносов; размер шрифта зависит от ширины блока. Восемь сцен сменяются с плавным переходом через девять секунд. Прозрачное управление находится по центру снизу: пауза/продолжение слева, затем точки выбора сцен; стрелок нет. При фокусе поле поиска меняет цвет иконки без рамки. Ввод в поле, неактивная вкладка и `prefers-reduced-motion` останавливают автопереходы. Загрузка страницы, аккаунта, заголовка и изображений имеет скелетоны.

В хедере анонимного посетителя — кнопка входа. Она передаёт ID `returnTo=/person/{locale}`. Парольный вход, регистрация, восстановление и OAuth сохраняют этот адрес; ID разрешает только известные локальные пути и переводит `/person/{locale}` в настроенный `PERSON_PUBLIC_URL`. Произвольные внешние redirect URL не принимаются. Существующий прямой вход в ID по умолчанию ведёт в его профиль.

Активная точка заполняется фиолетовым в течение девяти секунд. Заполнение и таймер сохраняют оставшееся время при паузе, фокусе в поиске и скрытии вкладки; следующая сцена начинает заполнение заново. Движение начинается после загрузки изображения, при `prefers-reduced-motion` индикатор статичен. Анимация выполняется в CSS без покадрового обновления React.

После входа хедер получает имя и аватар через серверный ID-клиент. Закрытый аватар выдаёт `/api/avatar` с `private, no-store`; JWT остаётся в HttpOnly cookie. Пункт «Моя страница» открывает подтверждённую персону либо экран заявки на создание; сессии и уведомления открываются в модальных окнах без перехода со страницы. Выход отзывает текущую сессию и удаляет cookie; другие устройства сохраняют доступ. При сбое отзыва cookie сохраняется, показывается ошибка для повторной попытки.

Общий gateway публикует ID на 3000, админку на 3001 и person на 3002. Сами Next-контейнеры не публикуют порты хоста. Gateway перезаписывает `X-Forwarded-For` IP соединения, затем BFF с `TRUST_PROXY=true` передаёт его ID с сервисным JWT. При запуске Next напрямую оставляйте `TRUST_PROXY=false`. Сессии хранят IP, User-Agent, ОС и версию, браузер, устройство, приложение, время входа и последней активности. GeoIP не подключён: регион остаётся пустым.

Локальные приложения используют один hostname (`localhost` для всех трёх портов). Основной production-домен, `id.` и `cms.` разделяют защищённую cookie через `SESSION_COOKIE_DOMAIN`; все публичные URL проверяются на HTTPS и принадлежность общему домену. Инструкция — [Nginx](../deployment/nginx_ru.md).

Проверки: `npm ci`, `npm run check`, `npm run build:prod`. Браузерные проверки против Compose: `npm run test:e2e`; сквозной тест с `E2E_LIVE_STACK=true` требует SMTP, направленного в локальный Mailpit. Не включайте его с внешним SMTP: тестовые адреса используют домен `example.test`.

[Отзывы, медиа, займы и личная страница](community_ru.md).

Внизу главной после загрузки и страниц персон закреплена нейтральная стеклянная бегущая строка без рамки: «Все персонажи вымышленные, совпадения случайны • На сайте используется контент, созданный с помощью ИИ». Загрузчик, 404, ошибки, блокировки и другие служебные страницы её не рендерят. Тексты локализованы на ru/en. В начале раздела «Настройки → Интерфейс» переключатель «Скрывать бегущую строку» сохраняет личный выбор в этом браузере. Главная и профиль учитывают высоту строки; при reduced motion тексты отображаются неподвижно с переносами. Компонент переиспользуется из `@persons/ui`; ID и CMS его не подключают.

CMS → «Управление → Интерфейс сайта» позволяет администратору выключить строку для всех посетителей. По умолчанию она включена; изменение сохраняется в `site_settings` (Flyway V18), вместе с автором и временем обновления, и применяется при открытии или обновлении страницы. `GET /v1/site-settings` возвращает публичную настройку без кэширования; чтение и запись `/v1/admin/site-settings` требуют администратора. При недоступной настройке основной контент остаётся доступен, строка скрывается, ошибка журналируется без чувствительных данных.
