# Предпросмотр игр

Откройте http://localhost:3002/ru/person/krel?preview=integrations. Раздел «Игры» доступен и без параметра; параметр выбирает вкладку сразу. В других профилях история пуста и показан Lifestealer с лицом Вадима. Для английского интерфейса замените ru на en.

Запуск: scripts/start-community-preview.ps1. Моковый API работает на 4310, история и лента загружаются через обычные сгенерированные клиенты/BFF. Четыре матча — дизайн-фикстуры, не реальные матчи профиля. Для ленты с тестовой сессией откройте http://localhost:4310/feed-session. CMS: http://localhost:4310/session.

В модалке есть ссылка на матч, KDA, длительность, ранг и предметы. Escape возвращает фокус на карточку. Проверьте прокрутку табов на узкой ширине, обе темы и пустое состояние. Изменения публичных динамических свойств в CMS приходят по SSE без перезагрузки страницы.
