# Яндекс Метрика

Основной сайт, ID и CMS используют один счётчик **113741427** через общий компонент `@persons/ui/analytics/YandexMetrika` в корневых layout. Дополнительные зависимости и переменные окружения не требуются.

Метрика включается только при `APP_ENV=prod`, на HTTPS и при совпадении текущего origin с `PUBLIC_URL`. На localhost, IP-адресах и в профилях `dev`/`testing` скрипт не загружается. Это относится и к локальному production Compose.

Скрипт загружается после гидратации и только при `PERSONS_OPTIONAL_COOKIES=accepted`. Существующий баннер основного сайта сохраняет выбор на общий `SESSION_COOKIE_DOMAIN`, поэтому он действует и в ID/CMS. При прямом посещении ID/CMS без этого выбора Метрика остаётся выключенной; согласие можно дать на основном сайте. После отказа счётчик останавливается через `destruct`; повторное согласие запускает его снова. Открытая вкладка другого приложения перечитывает выбор при получении фокуса.

Инициализация использует `defer: true`: первая страница и переходы Next.js отправляются явно через `hit`, без двойного автоматического просмотра. Повторный рендер, изменение исключённых параметров и hash не создают новые просмотры. Предыдущая страница передаётся как referer. В адресах сохраняются только `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, `yclid`, `ysclid`, `gclid`; остальные query-параметры, credentials и hash исключаются. Заголовок фиксирован и не содержит данных профиля.

Вебвизор, карта кликов, автоматическое отслеживание внешних ссылок, hash и Яндекс Тег Менеджер выключены. События бизнес-действий и цели пока не добавлены. Ошибка загрузки скрипта не блокирует приложение. Noscript-пиксель не установлен, поскольку он обошёл бы выбор cookie.

В настройках счётчика должны быть указаны основной домен, `id.` и `cms.`, включены фильтрация по адресам и поддомены. После выпуска трёх frontend-образов откройте сайт, примите cookie, перейдите между страницами и приложениями и проверьте счётчик в Метрике. Для проверки не передавайте реальные токены или персональные данные в UTM-метках. Отказ от cookie должен прекращать новые события. Локальные тесты подменяют SDK и не отправляют посещения в боевой счётчик.

Проверки: `npm test -- tests/yandexMetrika.test.tsx tests/cookiePreferencesRoute.test.ts src/shared/ui/CookieNotice/CookieNotice.test.tsx` из `frontend/person`; typecheck, lint и production build трёх приложений.
