# Объектное хранилище

ID и person используют разные базы PostgreSQL: `id` и `person`. В S3 находятся
файлы, в базах — их ключи и метаданные. Аватары и медиа выдаются через API/BFF
с проверкой видимости; смена провайдера не меняет публичные адреса файлов.

| Префикс | Содержимое |
| --- | --- |
| `achievments/` | Изображения достижений; написание папки выбрано пользователем |
| `video/` | Моменты, превью и варианты качества |
| `photo/` | Фотографии |
| `avatars/` | Аватары аккаунтов и персон |
| `proofs/` | Приватные доказательства владения страницей |
| `assets/` | Публичные иллюстрации, логотипы и иконки сайта |

Анонимное чтение разрешено только для `assets/*`. Не публикуйте весь бакет
или ключи доступа. Остальные файлы доступны через API с его проверками.
Оригинал и превью — соседние объекты `.../original` и `.../preview`:
имя оригинала не используется одновременно как префикс другого объекта.

Локально используется MinIO. Для внешнего S3 добавьте после production-файла
`-f docker/compose.external-s3.yaml`. В защищённом серверном `.env` задайте
`S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY` и
`ASSET_BASE_URL` — URL каталога `assets`. Для CI/CD запишите `external` в
`/opt/persons/shared/storage-profile`: релизы применят override и не будут
запускать локальный MinIO. По умолчанию профиль `local`. Исходный volume
автоматически не удаляется.

Загрузчик ассетов поддерживает оба режима и ограничивает публичную политику
каталогом `assets/*` выбранного бакета. При переносе сначала скопируйте объекты,
проверьте контрольные суммы и права. Для финальной синхронизации остановите
писателей, затем обновите ключи в базах и env. Сохраните исходное хранилище
и дампы до проверки нового. Перенос ключей — операционная миграция данных;
Flyway содержит только изменение схемы.

Подтверждённое удаление фото/видео ставит файлы, превью и варианты качества
на очистку в `person-worker`. Удаление достижения скрывает его из каталога
и ставит картинку на очистку; выключение `active` сохраняет её для повторного
включения. Замена картинки также ставит прежний объект в очередь. Проверка
выполняется раз в минуту; ошибки S3 оставляют запись для повторной попытки.
Незавершённые загрузки защищены 24 часа. ID перезаписывает постоянный ключ
аватара аккаунта; при выключенном versioning старые версии не накапливаются.

Проверки: `scripts/tests/storage.test.sh SERVER_IMAGE ASSETS_IMAGE` проверяет
оба режима и приватность файлов; `node --test ci/tests/external-s3.test.mjs`
проверяет внешнюю конфигурацию и раздельные адреса баз.
