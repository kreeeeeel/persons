# @persons/photo-editor

Переиспользуемый редактор аватарки.

`AvatarPicker` показывает круглый аватар с одной кнопкой файла без обводки справа снизу. `PhotoEditor` открывает фотографию с круглой областью обрезки, затемнением снаружи и нижней панелью: отмена, поворот, отражение по горизонтали и вертикали, «Применить». Углы изменяют размер квадратной рамки, сохраняя противоположный угол на месте; перетаскивание внутри рамки перемещает её по фото. Изображение при этом не меняет масштаб. Круг внутри рамки показывает результат для аватара; экспортируется именно выбранный фрагмент. Фото можно перемещать за пределами рамки и масштабировать колесом или жестом двумя пальцами. Углы и область доступны с клавиатуры: стрелки изменяют размер или положение, Shift ускоряет действие. Границы ограничены фотографией и адаптируются к размеру экрана.

Принимаются только JPG, PNG и статичный WebP до 10 МБ: каждая сторона от 256 до 8192 пикселей, не более 40 Мп, соотношение сторон до 4:1. MIME, расширение, сигнатура и размеры из заголовка проверяются до декодирования; затем проверяются реальные размеры декодированного изображения. Повреждённые и неподходящие файлы получают локализованную ошибку. Результат — JPEG 384×384 без исходных метаданных. Object URL очищается; во время чтения изображения показывается skeleton, во время сохранения — круглый спиннер. Используются react-easy-crop и Gravity Modal/Button. Нужны i18n namespaces `id` и `editor`.

`photoEditorMessages` из `@persons/photo-editor/messages` содержит общие UI fallback-переводы ru/en для обоих namespaces. Добавьте их в defaults приложения перед загрузкой переопределений из i18n API. Контент переводов не включается в миграции.

Source TypeScript + CSS Modules. Установите peers в приложении, добавьте пакет в Next transpilePackages. Локально: file dependency из frontend/id, после изменения — npm ci там же. Проверки: frontend/id npm run check и test:e2e. Собственный GitLab CI проверяет package и публикует в npm registry на default branch с версией 0.1.0-<pipeline iid>.

English: reusable React source package with CSS Modules. A single borderless file icon opens a circular preview with rotation, two mirrors and Apply. Drag a corner to resize the square selection around its opposite anchor; drag inside to move the selection without scaling the photo. The circular preview follows the selection and the selected source region is exported. Drag outside to pan the photo; wheel/pinch zoom remains available. Arrow keys resize or move the focused selection control, and Shift increases the step. Selection coordinates are bounded and remain proportional across screen sizes. Input is limited to still JPG/PNG/WebP, 10 MiB, 256–8192 pixels per side, 40 MP and a 4:1 aspect ratio. Headers are inspected before decoding, decoded dimensions are checked again, and output is a metadata-free 384×384 JPEG. Install peers in the consumer and enable Next transpilePackages. Checks run through frontend/id. The project CI validates packaging and publishes versioned packages to GitLab Registry; credentials come from CI variables.
