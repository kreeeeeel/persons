# Favicon

SVG, PNG и ICO используют портрет Вадима из `../logo.svg`. ICO содержит размеры 16, 32, 48, 64, 128 и 256px; Apple Touch Icon имеет непрозрачный светлый фон. Перед сборкой `tools/sync-assets.ts` копирует общий SVG и растровые иконки в metadata-файлы обоих Next.js-приложений. Исходная генерация и промпты описаны в [документации ассетов](../../../docs/assets/ru.md).
