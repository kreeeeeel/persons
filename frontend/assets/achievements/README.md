# Значки достижений

Сгенерированы встроенным `image_gen` с `transparent_background: true`. Каждый PNG — отдельный ресурс с настоящим альфа-каналом, без фоновой подложки. Точные промпты сохранены в [prompts.json](prompts.json) и [additional-prompts.json](additional-prompts.json). Для семи дополнительных значков образцами стиля служили `developer-v1.png` и `pleasant-person-v1.png`.

`scripts/seed-person-features.mjs` загружает изображения через API в S3 и сохраняет определения всех двенадцати значков в PostgreSQL. Сайт читает их через `/api/person/v1/achievements/{id}/image`. Демонстрационная выдача предусмотрена для значков разработчика и приятного человека; остальные определения доступны в админке.

Награды из [community-jokes.json](community-jokes.json), включая «Каблук» и «Тюрьма» с Евгением, импортирует `scripts/seed-achievements.mts`. Обе новые награды ручные: получателей выбирает администратор. Референс фотографии Евгения хранится вне репозитория; использован также существующий значок `borrow-lover-v2.png`. Генератор — встроенный `image_gen`; точные итоговые промпты сохранены в каталоге.

«Онлайн-футболист» использует референс Артёма и мотивы [REMATCH](https://www.playrematch.com/), «Деменция» — Никиту в шуточном сюжете о забывчивости, «Игрок в Доту» — Стёпу за клавиатурой с символикой Dota 2. Это три отдельные ручные награды с прозрачными PNG, созданные встроенным `image_gen`. Итоговые промпты и роли референсов сохранены в `community-jokes.json`; оригинальные фотографии остаются вне репозитория.

Проверка каталогов и PNG: `npm test --prefix frontend/assets` из корня проекта.

«Любитель уральских пельменей» — ручная награда с радующимся Вадимом и табличкой «УРАЛЬСКИЕ ПЕЛЬМЕНИ», посвящённая юмористическому шоу. Прозрачный PNG создан встроенным `image_gen` по согласованной фотографии Вадима и существующему значку `old-miller-lightweight-v1.png` как образцу стиля. Определение, точный промпт и роли референсов сохранены в `community-jokes.json`; оригинальная фотография остаётся вне репозитория.
