# Типографика Persons

Единая гарнитура интерфейсов — **Golos Text**, с кириллицей (включая Ё/ё) и латиницей, variable weights 400–900. Она рассчитана на читаемый русский интерфейс и используется в обеих темах.

Файлы, OFL-лицензия и единственное определение `next/font/local` находятся в `frontend/assets`. Приложение реэкспортирует `personsFont` как `uiFont` из `src/shared/theme/fonts.ts` и добавляет `uiFont.variable` к корневому HTML. Браузер получает локальный WOFF2, внешних запросов к сервисам шрифтов нет.

`@persons/theme/typography.css` задаёт публичные токены Gravity UI: основной текст, поля, кнопки и подписи — не меньше 16px; заголовки — вес 600. Размеры компонентов и line-height согласованы с этими токенами. Меню и диалоги используют ту же гарнитуру через `.g-root`.

Все три приложения подключают общий PostCSS-плагин `@persons/theme/postcss`. Он помещает только CSS пакета Gravity UI, включая отдельные стили компонентов, в слой `gravity`. Стили приложения остаются вне слоя и сохраняют приоритет независимо от порядка production-чанков. Стандартные PostCSS-преобразования Next.js сохранены в конфигурации. Нельзя исправлять порядок загрузки с помощью `!important` или повторных глобальных переопределений.

Не добавляйте отдельные font loaders или копии шрифта в новых приложениях. Импортируйте `@persons/assets/fonts`, подключайте общий theme provider и добавляйте пакеты в `transpilePackages`.

Проверки: наличие кириллицы в файле шрифта, фактическая гарнитура и размер полей, обе темы, центровка логотипа, флаг и язык в dropdown, отсутствие горизонтального скролла на 320/375/768/1440px. Перед визуальными проверками дождитесь `document.fonts.ready`.
